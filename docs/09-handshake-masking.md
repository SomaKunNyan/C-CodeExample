# 09. Если режут TLS-рукопожатие: фрагментация, маска, VLESS Encryption

## Можно ли зашифровать ClientHello REALITY

Нет. ClientHello — первое сообщение TLS, и до него у клиента и сервера нет общего ключа: оно
всегда идёт открытым текстом. Единственное штатное средство скрыть его содержимое — **ECH**
(Encrypted Client Hello), но:

* REALITY ECH не поддерживает — он как раз и показывает наблюдателю «правильный» ClientHello
  к настоящему сайту;
* ТСПУ в РФ с конца 2024 года блокирует сами ClientHello с расширением ECH.

Если провайдер режет **сам факт TLS-рукопожатия к вашему IP** (TCP проходит, а после ClientHello
или ServerHello соединение рвётся — видно в tcpdump, см. [05](05-operations.md)), остаётся
сделать так, чтобы оборудование провайдера **не узнало** в потоке начало TLS. В проекте три способа —
от простого к радикальному:

| | Фрагментация (`frag`) | Маска (`mask`) | VLESS Encryption (`enc`) |
|---|---|---|---|
| Что делает | ClientHello уходит кусками с паузами | весь поток REALITY перекодирован маской sudoku | TLS нет вовсе, свой протокол шифрования |
| Что видит DPI | обычный TLS, но «рваный» | печатные символы или шум без признаков TLS | случайные байты (или записи, похожие на TLS) |
| Изменения на сервере | **нет** | отдельный порт `MASK_PORT` | отдельный порт `ENC_PORT` |
| Защита рукопожатия | REALITY | REALITY (внутри маски) | ML-KEM-768 + X25519 |
| Скорость | как у REALITY | отдача медленнее (×4 трафика от клиента) | как у REALITY |
| Клиенты | Xray с finalmask: v2rayNG 2.3.14+ | Xray с finalmask: v2rayNG 2.3.14+ | Xray: v2rayNG, v2rayN, v2RayTun |
| Риск | дробленый ClientHello тоже бывает поводом для сброса | неопознанный протокол | неопознанный протокол, «полностью случайный» трафик |

Порт 443 во всех случаях остаётся обычным REALITY — прямые профили и вход через CDN не меняются.

## Фрагментация ClientHello (`frag`)

Сервер не меняется. Ссылка — та же, что у прямого REALITY, плюс параметр `fm` с маской
`fragment`: клиент отправляет ClientHello кусками по `FRAG_LENGTH` байт (по умолчанию 100–200) с
паузами `FRAG_DELAY` мс (10–20).

```bash
sudo ./scripts/vpn-user.sh link ivan frag
sudo ./scripts/vpn-user.sh selftest ivan frag     # REALITY принимает дробленый ClientHello
```

Если сброс приходит через несколько миллисекунд после отправки (как было с фрагментацией в
v2RayTun для CDN — `connection reset by peer` через 3 мс), провайдер реагирует на сам дробленый
ClientHello: попробуйте более крупные куски (`FRAG_LENGTH="400-600"`, `FRAG_DELAY="1-5"`) или
переходите к маске. Глобальную фрагментацию в настройках приложения при этом держите **выключенной** —
параметры уже в профиле.

## REALITY в маске (`mask`)

Отдельный вход REALITY на порту `MASK_PORT`, обёрнутый маской **sudoku** (finalmask Xray) с обеих
сторон. Маска перекодирует каждый байт в четыре «подсказки» судоку; в режиме `prefer_ascii` это
печатные символы — поток не похож ни на TLS, ни на случайный шум. Внутри маски — обычный REALITY
со всеми ключами, так что подменить сервер нельзя. Пароль маски выводится из закрытого ключа
REALITY и попадает в ссылку.

`config.env`:
```
MASK_ENABLE="yes"
MASK_PORT="46443"           # любой свободный TCP-порт
MASK_ASCII="prefer_ascii"   # или prefer_entropy
```
```bash
cd /opt/vpn-https-debian && git pull
sudo ./scripts/02-firewall.sh                    # откроет MASK_PORT (подтвердите SSH в течение 60 с)
sudo ./scripts/03-install-vpn.sh
sudo ./scripts/vpn-user.sh selftest ivan mask
sudo ./scripts/vpn-user.sh link ivan mask
```
Если у хостера есть firewall в панели — откройте там тот же порт.

Цена: всё, что клиент отправляет, занимает на линии в 4 раза больше (загрузка из интернета почти
не страдает — от сервера идёт упакованный вариант). Для сёрфинга и видео это незаметно, для
отправки больших файлов — заметно.

## VLESS Encryption (`enc`)

TLS нет совсем — см. [08](08-vless-encryption.md).

## Клиенты и параметр `fm`

Ссылки `frag` и `mask` содержат параметр `fm` — JSON маски finalmask. Его понимает **v2rayNG 2.3.14+**
(кладёт в `streamSettings.finalmask`). Приложение, которое `fm` не знает, молча подключится без
маски: `frag` тогда превратится в обычный REALITY, а `mask` не подключится вовсе. Проверить можно
в журнале приложения или, на компьютере, через `vpn-user.sh client-config ivan mask` — готовый
JSON-конфиг для `xray run -c`.

## Порядок проверки

1. `frag` — ничего не меняет на сервере, проверяется за минуту.
2. `mask` и `enc` — оба на своих портах; можно включить оба и сравнить, что проходит в вашей сети.
3. Проверяйте **в той сети, где режется**, с выключенными другими VPN и выключенной глобальной
   фрагментацией в приложении. Что пришло на сервер — `journalctl -u xray -f` (при
   `XRAY_LOGLEVEL="info"`) и `ss -tn 'sport = :46443'`.
