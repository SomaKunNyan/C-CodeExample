# 06. Сайты мимо VPN (split tunneling)

В отличие от OpenConnect, где сервер мог исключать только IP-сети, у VLESS маршрутизацию
выполняет **клиентское приложение** — поэтому исключения работают **по доменам**, точно и
вместе со всеми поддоменами, а DNS для исключённых сайтов идёт напрямую через провайдера клиента
(сайты, недоступные из-за рубежа, открываются).

Три способа — от простого к точному.

## 1. Встроенная настройка приложения (проще всего)

* **Hiddify** (все платформы): Настройки → «Регион» → **Россия** — российские домены (`.ru`, `.рф`,
  geosite) и российские IP идут напрямую. Подходит для «госуслуги, банки, маркетплейсы — без VPN».
* **v2rayNG / v2rayN**: в настройках маршрутизации есть готовые наборы правил; добавьте правило
  `direct` для нужных доменов (формат `domain:example.ru`) или `geoip:ru` / `geosite:category-ru`.

## 2. Свои правила в приложении

В v2rayNG / v2rayN / NekoBox / Streisand — раздел маршрутизации («Routing»), правило типа
**Direct** (напрямую):

| Запись | Что совпадает |
|---|---|
| `domain:example.ru` | `example.ru` и все поддомены |
| `full:www.example.ru` | только это имя |
| `geosite:category-ru` | российские сайты из базы geosite |
| `geoip:ru` | российские IP |
| `203.0.113.0/24` | сеть |

## 3. Готовый конфиг от администратора (`client-config`)

Список исключений хранится на сервере в `split-exclude.txt` (пример — `split-exclude.example.txt`):
```bash
cd /opt/vpn-https-debian
cp split-exclude.example.txt split-exclude.txt
nano split-exclude.txt                         # домены и сети, по одному на строку
sudo ./scripts/vpn-user.sh client-config ivan > ivan.json
```

`ivan.json` — полный конфиг Xray: подключение к серверу + правила `direct` для доменов и сетей из
списка + частные сети напрямую. Если в `config.env` задано `CLIENT_DIRECT_RU="yes"` — дополнительно
все российские сайты и IP. Конфиг импортируется в v2rayN / v2rayNG («Пользовательский конфиг» /
«Custom config») или запускается на Linux как `xray run -c ivan.json` (SOCKS5 на `127.0.0.1:10808`,
HTTP-прокси на `127.0.0.1:10809`).

Это конфиг **в формате Xray**: его понимают только приложения на ядре Xray (v2rayN, v2rayNG,
`xray` на Linux). Приложения на ядре **sing-box** (Hiddify, NekoBox, Karing, sing-box) его не
примут — для них используйте ссылку `vless://` и способы 1–2.

Файл содержит ключ доступа пользователя — передавайте его так же бережно, как ссылку.

## Проверка

* С включённым VPN откройте https://ifconfig.me — IP сервера; добавьте `ifconfig.me` в исключения —
  должен стать ваш домашний IP.
* Сайт из исключений должен открываться так же, как без VPN.

## Важно

* Трафик к исключённым сайтам идёт без VPN: сайт видит реальный IP пользователя, провайдер — факт
  обращения (содержимое защищено HTTPS самого сайта).
* Правила `geosite:`/`geoip:` берутся из баз, встроенных в приложение. Обновляйте приложение или
  geo-базы в его настройках.
