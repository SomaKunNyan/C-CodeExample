# =============================================================================
#  Исключения из VPN (split tunneling) для клиентских конфигов.
#  Скопируйте:  cp split-exclude.example.txt split-exclude.txt
#  Конфиг клиента: sudo ./scripts/vpn-user.sh client-config <имя>
#
#  Трафик к перечисленным доменам/сетям пойдёт с устройства клиента НАПРЯМУЮ,
#  мимо VPN: сайт увидит реальный IP клиента. Маршрутизацию выполняет
#  клиентское приложение, поэтому домены работают точно (по имени, а не по IP),
#  и запись домена охватывает ВСЕ его поддомены.
#
#  Формат: одна запись на строку, всё после # — комментарий.
#    example.com          домен и все поддомены (www., api., ...)
#    203.0.113.0/24       сеть (CIDR)
#    198.51.100.7         отдельный адрес
#  Кириллические домены можно писать как есть (госуслуги.рф).
# =============================================================================

# sberbank.ru
