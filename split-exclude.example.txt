# =============================================================================
#  Исключения из VPN-туннеля (split exclude).
#  Скопируйте:  cp split-exclude.example.txt split-exclude.txt
#  и примените: sudo ./scripts/update-split-routes.sh
#
#  Трафик к перечисленным доменам/сетям пойдёт с устройства клиента НАПРЯМУЮ,
#  мимо VPN: сайт увидит реальный IP клиента.
#
#  Формат: одна запись на строку, всё после # — комментарий.
#    example.com          домен (разрешается в A/AAAA; поддомены — отдельно!)
#    www.example.com
#    203.0.113.0/24       сеть (CIDR) — для сервисов с известными диапазонами
#    198.51.100.7         отдельный адрес
#  Кириллические домены можно писать как есть (госуслуги.рф).
#  Маски *.example.com не поддерживаются: DNS не позволяет узнать все поддомены.
#
#  Важно: на CDN (Cloudflare, Akamai...) один IP обслуживает тысячи сайтов —
#  вместе с доменом мимо туннеля пойдут и они.
# =============================================================================

# example.com
# www.example.com
# 203.0.113.0/24
