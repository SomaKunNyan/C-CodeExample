# Формат — по одной записи в строке:
#   example.com          домен со всеми поддоменами
#   full:www.example.com только это имя
#   geosite:netflix      готовый список доменов из geosite.dat
#   203.0.113.0/24       сеть;  geoip:XX — страна или список из geoip.dat
# Несуществующий тег geosite/geoip не даст применить конфиг (03-install-vpn.sh скажет).
